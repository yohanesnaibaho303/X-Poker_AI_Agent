# Architecture Decision Records

Major architecture, safety, data, and licensing choices are recorded here as short ADRs.

Status values are `Proposed`, `Accepted`, `Superseded`, or `Rejected`. New records use the next numeric prefix and should describe context, decision, consequences, and alternatives. Superseded records remain in the repository for history.
