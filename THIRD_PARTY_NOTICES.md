# Third-Party Notices

## GTOpen generated strategy evidence

Files under `data/ranges/gtopen/` were generated by running GTOpen externally at commit
`4aee435bdeb155b25f0c8140e707a8342ce4356f`. The user attested direct authorization from GTOpen
owner Matthew PDingle for private educational use, including permission to reuse code and binaries.
The current integration runs GTOpen externally and does not vendor its source or binary because that
would add no runtime benefit. Upstream source: <https://github.com/MatthewPDingle/GTOpen>.

Generated results are equilibrium outputs of GTOpen's documented 169-class, pairwise-equity,
multiway preflop model. They are marked as model-abstracted and are not represented as an exact
full-game equilibrium.

## preflopR reference range data

The generated files under `data/ranges/preflopr_reference/` derive their 169-class raise/fold
membership from `bmorrow10/preflopR`, pinned at commit
`aed511d0451aea33a14f7e9204595fc2211f233f`. The importer and X-Poker Agent data model are independent
project code. Upstream source: <https://github.com/bmorrow10/preflopR>.
